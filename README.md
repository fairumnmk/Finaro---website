# FINARO Website

Static website prepared for GitHub Pages.

## Upload to GitHub
1. Extract this ZIP.
2. Open your `finaro-website` GitHub repository.
3. Upload `index.html`, `style.css`, and `.nojekyll` to the repository root.
4. Commit the files.
5. Go to Settings > Pages.
6. Set Source to **Deploy from a branch**.
7. Select **main** and **/(root)**, then Save.

Do not configure `finarouae.ae` as a custom domain until you purchase the domain and configure its DNS.
